# 🍗 KFC copy — Estudo de UI/UX 

Criei este projeto para aprender e colocar em prática conceitos de **UI/UX Design** e **Customer Experience (CX)**, explorando como o design de uma interface pode tornar a experiência de quem navega mais simples, agradável e intuitiva.

A proposta foi desenvolver uma experiência inspirada no KFC, com um cardápio visual, navegação responsiva e interações que facilitam a descoberta dos produtos. No mobile, busquei uma experiência semelhante à de um aplicativo; no desktop, adaptei a organização dos elementos para aproveitar melhor o espaço da tela.

Durante o desenvolvimento, pratiquei hierarquia visual, consistência de cores, espaçamento, responsividade e organização dos fluxos de navegação. Também trabalhei com favoritos, sacola de pedidos, notificações e suporte a português, inglês e espanhol.

Foi muito interessante aprender um pouco mais sobre a **comida americana**, conhecer diferentes produtos e perceber como a apresentação de um cardápio pode influenciar a experiência do cliente. O projeto uniu esse interesse à oportunidade de experimentar, revisar e melhorar minhas decisões de design.

## Sobre o projeto

Este é um **projeto independente, desenvolvido para fins educacionais**, sem vínculo oficial com o KFC. A sacola e os pedidos são demonstrativos; os preços, ofertas e avaliações apresentados são ilustrativos. As marcas pertencem aos seus respectivos titulares.
